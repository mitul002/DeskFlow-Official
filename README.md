# DeskFlow Official

**DeskFlow** is a smart office productivity app for tracking work sessions, breaks, and daily activity — built with a premium Fluent Dark theme.

## Download

Download the latest installer from the [Releases](https://github.com/mitul002/DeskFlow-Official/releases/latest) page.

## Features

- ⏱️ Office session timer with break tracking (Lunch, Prayer, Custom)
- 📊 Analytics dashboard with weekly history
- 🔔 System tray support with quick actions
- 🌙 Premium Fluent Dark UI
- 🔑 License-based access with trial period
- 🔄 Automatic update detection

## Installation

1. Download `DeskFlow_Setup.exe` from Releases
2. Run the installer and follow on-screen instructions
3. DeskFlow will launch automatically after installation
